# Interview Simulator UI kit

Mock-interview session with voice/text input and live AI coaching.

**Components**
- `InterviewerCard` — simulated interviewer header (avatar, name, role, timer, "live" indicator)
- `QuestionCard` — current question with category tag
- `Transcript` — conversation bubbles (AI and user)
- `MicBar` — record/listen control with waveform + "type instead" fallback
- `FeedbackPanel` — live metrics (clarity / specificity / pacing / confidence / filler words) + coaching cards
