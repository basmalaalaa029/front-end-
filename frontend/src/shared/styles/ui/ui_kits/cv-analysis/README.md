# CV Analysis UI kit

Score dashboard for a CV against a specific target role.

**Components**
- `ScoreHero` — animated ring + headline verdict + sub-score grid
- `CritCard` — section-by-section critique (pass / needs-work / gap) with an AI-rewritten fix
- `GapMatrix` — keyword & skill coverage bars

Target-bar at top binds the analysis to a specific role + company.
